# Support

[简体中文](SUPPORT.zh-CN.md) · [Project README](README.md)

FIRE is a personal financial-planning scenario tool, not a financial advisory service. Please use the channel that matches your request:

- **Bug reports:** open an issue using the [Bug report form](https://github.com/LiSichao/fire/issues/new?template=bug_report.yml). Include reproducible steps and synthetic example inputs.
- **Feature ideas:** use the [Feature request form](https://github.com/LiSichao/fire/issues/new?template=feature_request.yml) and explain the user problem being solved.
- **Questions about behavior or formulas:** first review the [README](README.md) and [calculation model](docs/calculation-model.md). If the documentation does not answer the question, open a question issue with the relevant field names and non-sensitive example values.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md). Do not disclose an unpatched vulnerability in a public issue.

## Protect your privacy

Never include real financial statements, account numbers, passwords, access tokens, identity documents, or other sensitive personal information in an issue, pull request, log, or screenshot. Replace real inputs with synthetic values before sharing examples.

## What this project does not provide

The score, peer percentile, required-return output, and projected balances are based on simplified assumptions in the code. They are not a guarantee, investment recommendation, tax computation, legal opinion, pension eligibility determination, or individualized financial advice.
