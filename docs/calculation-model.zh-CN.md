# 计算模型与假设

[English](calculation-model.md) · [项目主页](../README.zh-CN.md)

本文描述 `pages/index/index.js` 当前实际实现的行为，是对代码的技术说明，并不表示该模型覆盖了完整的个人财务问题，也不表示相关指标经过了实证验证。

## 1. 规划周期与金额单位

模型会生成 `max(0, 目标年龄 - 起始年龄)` 条年度现金流记录。第 `i` 条记录对应公历年份 `当前年份 + i` 和年龄 `起始年龄 + i`。余额序列包含初始余额以及每个模拟年度结束后的余额，因此最后一个点对应目标年龄。

内部的余额和大部分年度收入/支出以**人民币万元**表示。界面输入项采用以下单位：

| 输入项 | 单位 |
| --- | --- |
| 初始本金、目标存款、起始年收入 | 万元 |
| 水电费、燃油/充电、停车费、房租、物业费、宠物、自定义科目 | 元/月 |
| 宽带和通讯 | 元/年 |
| 日常开销 | 元/人/月，再乘以人数 |
| 孝亲费、旅游、教育、保险/医疗 | 万元/年 |
| 车贷和房贷月供 | 元/月 |
| 公积金和社保金额 | 元/月 |
| 收入增长率、通胀率、可用/计入比例 | 界面显示百分比，内部转换为小数 |

输入时尤其要注意元/月与万元/年并存的情况，应始终以界面字段标注为准。

## 2. 年收入模型

对第 `i` 个模拟年度，源码按以下公式计算：

```text
steps = min(i, max(0, growthYears - 1))
年收入(i) = 起始年收入 × (1 + 年收入增长率)^steps
```

`增长持续年数`包含起始年。收入在设定的增长期内按配置增长，增长期结束后保持不变。模型不会单独对收入应用通胀，也不模拟个税、奖金、失业或薪酬波动。

## 3. 支出与通胀

年度支出由以下类别组成，金额统一折算为万元：

- **A — 固定开销：** 水电费、燃油/充电、停车费按 12 个月计算，宽带/通讯按年度金额计算。
- **B — 日常开销：** 每人每月开销 × 人数 × 12。
- **C — 年度大项：** 孝亲费 + 每人旅游费 × 旅游人数。
- **D — 车贷：** 在设置的起止年份范围内，月供乘以该年度模拟的还款月数。
- **E — 住房：** 房贷月供 + 房租/物业费。房租和物业费随通胀变化；房贷月供不随通胀变化。
- **F — 其他开销：** 宠物月支出 × 12 + 年度教育 + 保险/医疗。
- **G — 自定义开销：** 两个自定义月度项目分别乘以 12。

A、B、C、F、G 类支出，以及 E 类中的房租/物业费，使用下式应用通胀：

```text
通胀因子(i) = (1 + 年通胀率)^i
通胀后支出(i) = 基础支出 × 通胀因子(i)
```

车贷和房贷月供不做通胀调整。收入模型以名义金额表示，不会自动随通胀增长。

### 贷款日期处理

只有在设定起止年份（含）范围内的年份才计入月供。结束年份之前的每个还款年度按 12 个月计，结束年份按设定的结束月份计入最多相应月数。没有起始月份字段，因此起始年份被视为完整还款年。当前实现不拆分贷款本金与利息，不模拟提前还款，也不计算贷款机构的真实摊还计划。

## 4. 额外储蓄项

模型允许将用户设置的部分公积金和社保金额计入年度储蓄：

```text
年度公积金计入额 = 公积金月缴金额 × 12 × 可用比例
年度社保计入额 = 社保月缴金额 × 12 × 养老金计入比例
额外储蓄 = (年度公积金计入额 + 年度社保计入额) / 10,000
```

每年的额外储蓄也会乘以对应的通胀因子。这些比例由用户自行设定，不是对法定资格、账户归属、提取规则、养老金待遇或法律权益的计算。

年度结余为：

```text
年度结余 = 年收入 - 年度总支出 + 额外储蓄
```

模型允许年度结余为负数，并据此减少模拟余额。

## 5. 余额增长模型

对年化收益率 `r` 和年度结余 `s[i]`，实现使用：

```text
balance[0] = 初始本金
balance[i + 1] = balance[i] × (1 + r) + s[i]
```

也就是先让上一期余额按年化收益率增长，再加入当年的年度结余。这不是按月投入模型，当年结余不会获得该年度的年内投资增长。收益率是确定性的：每年使用同一个收益率，不模拟波动、回撤、顺序风险、管理费、税费或再平衡。

## 6. 两种计算模式

### 模式 A — 反推所需收益率

二分法会反复计算期末余额并缩小收益率搜索区间，直到区间宽度低于 `1e-7` 或达到最大迭代次数。搜索范围为每年 **−0.50 至 +1.00**，即 −50% 至 +100%。

源码包含以下特殊处理：

- 目标存款小于或等于零时，返回 0 收益率。
- 如果初始本金已经达到/超过目标，且所有年度结余都非负，则返回 0 收益率。
- 搜索范围是有限的。在边界处显示的结果不能证明所设目标一定可行。

界面中显示的通胀调整收益率采用简单近似 `名义收益率 - 通胀率`，而不是精确的 Fisher 关系式。因此它只能作为提示性标签。

### 模式 B — 推算最终存款

主收益率滑块的范围是 0% 至 15%。程序按该收益率计算最终余额；用户还可以选择 3%、5%、7% 和 10%、12% 的收益率对比曲线。

界面显示的“相当于今天购买力”通过最终余额除以 `(1 + 通胀率)^年数` 得到。它只根据所选通胀假设对名义终值做折算，不模拟生活方式变化、税费或资产实际回报变化。

## 7. 规划指数与同龄人百分位

源码计算一个 0–100 分的指数，包含五个维度：

| 维度 | 最高分 |
| --- | ---: |
| 储蓄率 | 25 |
| 所需收益率的可行性 | 25 |
| 收入增长假设 | 20 |
| 支出结构 | 15 |
| 目标金额相对于起始年收入的规模 | 15 |

该分数由源码中的固定阈值规则计算。提示文案会找出归一化得分最好和最弱的维度，并选取一条预设建议。同龄人百分位则使用代码中硬编码的年龄组均值和标准差，通过近似正态分布累积分布函数计算。

重要限制：

- 百分位**不是**来自实时或有来源引用的调查、银行数据集或代表性人群样本。
- 评分的部分子计算使用简化的当前支出估算，不保证与逐年现金流模型完全一致。例如，评分辅助函数未计入车贷月供。
- 高分或较高百分位不能证明一定能实现财务自由，也不代表经过验证的真实同龄人比较。

## 8. 假设与未覆盖因素

当前模型没有显式覆盖：

- 个税、社保从到手收入中的扣除，以及税法变化；
- 投资管理费、交易成本、投资收益税、投资组合波动；
- 资产配置、股息/票息、现金拖累、再平衡和收益顺序风险；
- 不规律收入、失业、大额意外支出或家庭成员变化；
- 完整的房贷/车贷摊还计划、提前还款及年内现金流日期；
- 单独的退休后支出与提款阶段；
- 对规划指数或同龄人比较假设的实证验证。

请用 FIRE 探索“如果这些假设成立，会发生什么”，而不是把结果当作“未来一定会怎样”。建议使用保守假设，并对关键输入进行压力测试。
