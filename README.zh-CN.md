# FIRE 财务自由规划器 | Financial Independence, Retire Early

**把财务自由从目标变成可推演的路径。** FIRE 是 Financial Independence, Retire Early（财务独立、提前退休）的规划工具，通过微信小程序模拟收入、支出、储蓄、通胀与投资收益情景，核心计算在客户端完成。

[English](README.md) · [计算模型与假设](docs/calculation-model.zh-CN.md) · [贡献指南](CONTRIBUTING.zh-CN.md) · [行为准则](CODE_OF_CONDUCT.zh-CN.md) · [安全策略](SECURITY.zh-CN.md) · [使用支持](SUPPORT.zh-CN.md) · [许可证](LICENSE) · [GitHub 仓库配置建议](GITHUB_REPOSITORY_SETUP.zh-CN.md)

> **重要声明：** FIRE 仅用于学习、情景分析与个人规划，不是金融产品、投资建议、税务计算器或养老金计算器，也不保证未来结果。输出取决于用户填写的假设以及经过简化的年度模型。

## 项目概览

FIRE 帮助用户将长期财务目标拆解为可编辑的年度现金流场景。用户可以设置年龄区间、初始资产、收入增长、通胀、住房和日常支出、贷款期限，以及公积金/社保的可计入比例。小程序在本地重新计算，并以图表展示不同年化收益率假设对期末资产的影响。

### 功能特性

- **双计算模式**
  - **反推收益率：** 设置目标存款，估算在当前现金流假设下达到目标所需的年化收益率。
  - **推算最终存款：** 设置年化收益率，估算目标年龄时的存款余额。
- **可编辑的年度现金流模型：** 支持收入增长、通胀、家庭日常开销、年度支出、车贷、房贷、房租和物业费。
- **多分区参数面板：** 基础参数、收入、通胀、固定开销、日常消费、年度大项、车贷、住房、其他支出、自定义科目，以及公积金/社保抵扣假设。
- **9 个预设场景：** 覆盖职场新人、攒首付、DINK、备孕、有娃、中年转型、双娃家庭、高管和临退休等情景。
- **4 个图表：** 年度收入与支出对比、支出结构、不同收益率下的存款累积曲线、年度结余分解。
- **收益率对比：** 可选择同时比较 3%、5%、7%、10% 和 12% 的年化收益率情景。
- **0–100 分启发式规划指数：** 汇总储蓄率、目标可行性、收入增长假设、支出结构和目标规模，并给出基于年龄分组参数的百分位估算。
- **快速反馈：** 输入变化经过防抖后触发重算；当前实现不需要单独启动服务端。

预设场景和评分只是辅助理解的工具，并不代表任何目标或收益率一定能够实现。

## 快速开始

### 环境要求

- [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
- 微信小程序 AppID，或开发者工具环境提供的测试项目选项
- 本仓库源码

当前仓库的 `project.config.json` 将小程序基础库版本设置为 `3.17.0`，且 AppID 为空。请在开发者工具中配置适用于你自己的 AppID 和开发环境。

### 本地运行

1. 克隆或下载仓库：

   ```bash
   git clone https://github.com/LiSichao/fire.git
   cd fire
   ```

2. 打开微信开发者工具。
3. 选择**导入项目**，项目目录选择仓库根目录，即同时包含 `app.json` 和 `project.config.json` 的目录。
4. 如开发环境要求，请在开发者工具中配置自己的 AppID。
5. 编译并在模拟器中运行。正式依赖平台渲染或触摸交互前，应在真实设备上验证。

当前源码中没有 `package.json`、独立的 Node 构建脚本或服务端程序。图表运行时已放在 `components/ec-canvas/` 下，当前实现不需要另外启动后端服务。

## 使用流程

1. **先加载预设场景**，了解一组完整参数；也可以直接填写自己的假设。
2. **设置规划周期**，目标年龄必须大于起始年龄。
3. **填写收入与开销**。请仔细留意字段单位：部分是每月人民币元，部分是每年万元。
4. **选择计算模式**。反推模式需要设置目标存款；推算模式需要设置主收益率，也可以勾选对比收益率。
5. **同时检查结果卡片和四张图表**。图表看起来合理，并不等于输入假设可靠。
6. **每次调整一个假设**，观察结果如何变化；点击“全部重置”可恢复默认参数。

关于公式、单位与模型限制，请阅读[计算模型与假设](docs/calculation-model.zh-CN.md)。

## 输入参数速查

| 分区 | 参数 | 说明 |
| --- | --- | --- |
| 基础参数 | 起始年龄、目标年龄、初始本金、目标存款 | 本金和目标存款单位为万元。 |
| 收入 | 起始年收入、年增长率、增长持续年数 | 按年度建模，超过设定增长期限后收入保持不变。 |
| 通胀 | 年通胀率 | 用于部分支出类别和模型中的额外储蓄项；不直接作用于收入和贷款月供。 |
| A — 固定开销 | 水电费、充电/燃油、停车费、宽带/通讯 | 前三项为元/月；宽带/通讯为元/年。 |
| B — 日常开销 | 每人每月支出、人数 | 元/月。 |
| C — 年度大项 | 孝亲费、每人旅游费、旅游人数 | 金额单位为万元/年。 |
| D — 车贷 | 月供、起止年份、结束月份 | 没有起始月份字段；起始年份按完整还款年处理。 |
| E — 住房 | 房贷月供和日期、房租、物业费 | 房贷按年度统计；房租和物业费随模型通胀增长。 |
| F — 其他支出 | 宠物、子女教育、保险/医疗 | 宠物为元/月；教育和保险/医疗为万元/年。 |
| G — 自定义 | 两个可命名的月度支出项 | 每项元/月。 |
| H — 公积金/社保 | 月缴金额、可用/计入比例 | 按用户填写的比例折算为额外年度储蓄，不是法定待遇计算。 |

## 计算模型概览

实现按年生成现金流记录。简化公式如下：

```text
年度结余 = 年收入 − 模型计算的年度支出 + 模型计算的额外储蓄
期末余额 = 期初余额 × (1 + 年化收益率) + 当年结余
```

- **反推收益率模式**使用二分法，在**−50% 至 +100%** 的年化收益率区间内寻找使期末余额接近目标的收益率。
- **推算最终存款模式**先按所选年化收益率增长期初余额，再加上当年的模型结余。
- **通胀处理**使用 `(1 + 通胀率)^年度索引`，对指定支出类别增长。
- **规划指数和同龄人百分位**使用代码内置的规则及年龄组分布参数，不依赖实时、可引用或经过独立验证的总体统计数据。

这些简化使计算能够快速响应，适合做假设比较，但并未覆盖真实财务生活中的全部因素。解读结果前请阅读[完整模型说明](docs/calculation-model.zh-CN.md)。

## 隐私与数据处理

页面和计算代码中没有自定义后端、`wx.request` 或 `wx.cloud` 调用。输入值通过 `wx.setStorageSync` 保存在本机（键名 `fire_params`，数据版本 1），启动时自动恢复，因此关闭再打开小程序后情景仍在，不会上传到任何服务器。

缓存内容包括输入值、当前计算模式、折叠面板展开状态和最近一次加载的预设。「全部重置」会用默认值覆盖该记录；清除小程序缓存或卸载也会一并清除。数据不会跨设备同步。

这仅描述本次检查的仓库代码，并不构成对微信或设备平台层面数据处理行为的保证。请另行查阅微信平台的隐私条款，并检查你自己的小程序配置。

## 使用边界与限制

- 结果是情景模拟，不是预测。实际收入、支出、通胀和投资回报可能与输入差异很大。
- 模型以年度为单位，不模拟年内资金时点、税费、投资组合波动、管理费用、资产配置或退休后的提款策略。
- 贷款的日期粒度有限，没有完整模拟摊还计划或提前还款。
- 公积金和社保被简化为用户自定义比例对应的额外储蓄，不用于判断资格、账户余额、法定待遇或法律权益。
- 财务自由指数和同龄人百分位是启发式指标，不是经过验证的财务健康评价或具有代表性的统计结论。
- 反推收益率范围为 −50% 至 +100%；极端或无法实现的参数组合可能在边界处得到结果，不应脱离模型假设解读。
